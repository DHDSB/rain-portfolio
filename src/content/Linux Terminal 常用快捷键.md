# Linux Terminal 常用快捷键

## 移动光标

```
Ctrl + A           Ctrl + E
跳到行首            跳到行尾

Alt + B            Alt + F
向左跳一个单词      向右跳一个单词  
```

## 删除

```
Ctrl + U           Ctrl + K 
删除光标前所有内容   删除光标后所有内容

Ctrl + W           Alt + D
删除前一个单词      删除后一个单词
```

## 历史命令

```
Ctrl + R           Ctrl + G
进入历史命令搜索    退出历史命令搜索
```

## 任务控制

```
Ctrl + C
终止程序

Ctrl + Z
挂起程序

```

## 清屏

```
Ctrl + L
等价于clear
```

## Bash补全

```
Tab
自动补全

Tab Tab
查看所有可能选项

!!
执行上一条命令

!$
上一条命令的最后一个参数

```
